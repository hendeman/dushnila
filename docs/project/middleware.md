# `skinali/skinali/middleware.py`

## Назначение

Модуль содержит небольшой middleware, который не позволяет техническому preview-сайту попасть в поисковый индекс.

## `SearchEngineIndexingMiddleware`

Middleware выполняется сразу после стандартного `SecurityMiddleware`. Если `settings.SITE_NOINDEX=True`, он добавляет к каждому ответу заголовок `X-Robots-Tag: noindex, nofollow`. Настройка включается автоматически только профилем `DJANGO_ENVIRONMENT=preview`; development и production её не получают.

Заголовок применяется к HTML, sitemap, ответам ошибок и другим типам содержимого без изменения шаблонов и без запросов к БД. Дополнительно preview-версия `robots.txt` возвращает `Disallow: /`.

## Ограничения

Запрет индексации не является контролем доступа и не защищает передаваемые по HTTP данные. На техническом домене без HTTPS нельзя использовать настоящие пароли, токены или персональные данные.

## Когда читать исходник

При изменении preview-профиля, политики индексации технических окружений или состава middleware.
