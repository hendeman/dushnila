# `skinali/manage.py`

## Назначение

Стандартная точка входа Django для административных команд из командной строки.

## Публичные компоненты

- `main()` устанавливает `DJANGO_SETTINGS_MODULE=skinali.settings`, импортирует `execute_from_command_line` и передает ему `sys.argv`.
- Блок `if __name__ == '__main__'` вызывает `main()` при прямом запуске файла.

## Использование

Команды запускаются из каталога `skinali/`, например `python manage.py runserver`, `python manage.py migrate`, `python manage.py test`.

## Зависимости

- Стандартные модули `os`, `sys`.
- Django и конфигурация [settings.py](settings.md).

## Особенности и риски

При невозможности импортировать Django выбрасывается поясняющий `ImportError`. Пользовательских management-команд в проекте сейчас нет.

## Когда читать исходник

При изменении механизма запуска, переменной настроек или добавлении поведения до/после выполнения management-команд.
