# `skinali/pict/admin.py`

## Назначение

Настраивает Django Admin для всех моделей каталога и регистрирует их на сайте admin.

## `PictAdmin`

### Список записей

- 20 записей на страницу.
- Колонки: номер, миниатюра, категории, цвета.
- Ссылка открывается по полю `name`.
- Поиск: `name`, `tags__tag`.
- Фильтры: время добавления, категория, цвет.
- Сортировка: `-id`.

### Форма записи

- Поля: `name`, `alt`, `photo`, увеличенное превью, `time_update`, `color`, `cat`, `tags`.
- Только для чтения: `time_update`, увеличенное превью.
- Для `color`, `cat`, `tags` применяется горизонтальный виджет выбора.
- Используется [PictAdminForm](forms.md).

### Вспомогательные методы

- `get_html_photo(object)` возвращает кликабельное изображение шириной 150 px.
- `get_html_photo_fields(object)` возвращает кликабельное изображение шириной 400 px.
- `get_list_category(object)` соединяет названия категорий через запятую.
- `get_list_color(object)` соединяет названия цветов через запятую.

Для HTML-превью применяется `mark_safe`; URL берется из `object.photo.url`.

## Остальные admin-классы

- `CategoryAdmin`: показывает `cat`, `slug`; поиск по `cat`; slug автозаполняется из названия.
- `TagPictAdmin`: показывает `tag`, `slug`; поиск по `tag`; slug автозаполняется из тега.
- `ColorAdmin`: показывает `color`, `slug_color`; сортирует по названию цвета. Автозаполнение slug закомментировано.

## Регистрация

Зарегистрированы пары `Pict/PictAdmin`, `Category/CategoryAdmin`, `Color/ColorAdmin`, `TagPict/TagPictAdmin`.

## Особенности и риски

- HTML строится f-строкой и помечается безопасным; сейчас вставляется URL из `ImageField`, но при изменении источника данных нужно учитывать XSS.
- Методы списка категорий и цветов выполняют обращение к ManyToMany для каждой строки; `get_queryset()` с `prefetch_related()` не переопределен.
- Аргумент методов назван `object`, перекрывая встроенный тип Python, но на работу это не влияет.

## Когда читать исходник

При изменении интерфейса admin, полей формы, поиска, фильтров, превью или производительности списка.
