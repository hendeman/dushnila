# `skinali/pict/forms.py`

## Назначение

Содержит `ModelForm`, используемую административной панелью при редактировании `Pict`.

## `PictAdminForm`

- Наследуется от `forms.ModelForm`.
- Привязана к модели `Pict`.
- Явно включает только поле `name`.
- В `__init__()` устанавливает `self.fields['name'].initial = self.instance + 1`.

Выражение вызывает `Pict.__add__(1)`, который берет `name` первой записи с учетом сортировки модели (`-id`) и прибавляет единицу. Цель — автоматически предложить следующий номер при добавлении изображения.

## Зависимости

- [models.py](models.md): модель `Pict` и ее `__add__()`.
- [admin.py](admin.md): `PictAdmin.form = PictAdminForm`.

## Особенности и риски

- Инициализация зависит от запроса к таблице `Pict` внутри `Pict.__add__()`.
- На пустой таблице вычисление начального значения может завершиться ошибкой.
- При редактировании существующей записи initial также вычисляется заново, хотя сохраненное значение instance обычно имеет приоритет при отображении bound model form.
- Поля `alt`, `photo`, `time_update`, `color`, `cat`, `tags` перечислены в `PictAdmin.fields`, но отсутствуют в `ModelForm.Meta.fields`. Перед изменением формы нужно проверить поведение Django Admin с такой комбинацией.

## Когда читать исходник

При изменении автоматической нумерации, состава/валидации полей или формы admin.
