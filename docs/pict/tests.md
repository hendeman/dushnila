# `skinali/pict/tests.py`

## Назначение

Стандартный модуль Django для тестов приложения `pict`.

## Текущее состояние

Модуль содержит 83 теста. Отдельные одиннадцать тестов редактируемого меню находятся в `sitecontent/tests.py` и описаны в [документе приложения](../sitecontent/overview.md). Класс `PopularTagsTests` проверяет формирование популярных тегов в каталоге и главную страницу:

- общий каталог и каждая страница категории используют один глобальный набор тегов и глобальные счетчики по опубликованным изображениям;
- теги отсортированы по убыванию количества изображений;
- список ограничен десятью элементами;
- в HTML выводится название тега без значения счетчика;
- изображения каталога размечены отдельной Fancybox-группой `catalog-gallery`; каждое превью показывает номер в левом верхнем углу, а модальный шаблон содержит `alt`, теги, номер, категории, внутренние стрелки, кнопки избранного/покупки и расположенную после покупки раскрываемую публикацию полноразмерного файла через Telegram, Viber и WhatsApp, но не содержит счётчика;
- общий каталог сохраняет такое же ограничение в десять тегов.

- первым пунктом категорий выводится «Все»: ссылкой внутри категории и выбранным элементом в общем каталоге.
- ссылки «Все» и категорий сохраняют выбранный GET-параметр `color`, но не добавляют его без активного цветового фильтра.
- без выбранного цвета выводится «Все цвета», а при выборе — белый круг-маркер, сохраненная серая обводка блока и ссылка «Сбросить цвет» с крестиком в независимой правой колонке;
- мобильная разметка содержит две кнопки фильтров, полноэкранные диалоги категорий и цветов, выбранные пункты с галочками и подключение `mobile-filters.js`;
- базовый шаблон содержит отдельные информационную панель и панель главного меню, темный логотип шапки и отдельный светлый логотип футера, режим работы, телефонную ссылку, адаптивную кнопку меню, единый раскрывающийся список навигации, темный футер, полноширинный `site-main`, прозрачный контейнер `site-content`, версию `v=72` общего CSS со стилями хлебных крошек, овального меню категорий и пагинации, трехколоночную десктопную сетку, а также подключения `site-menu.js` и клиентского модуля публикации изображений; поисковая капсула находится только в шаблоне каталога;
- поисковая форма каталога содержит подсказку «Поиск, например море»;
- в разметке фиксированной модальной карточки каталога присутствует переключатель «Добавить в избранное»/«Удалить из избранного», шаблон подписи, fade-настройка Fancybox без штатной навигации, отключённые начальный zoom и Hash-плагин истории, отложенное проявление полностью подготовленного `contentEl` и блокировка запуска Panzoom из выделяемой текстовой области; четыре интерактивные кнопки подписи помечены `data-clickable`, а обработчик выделяемой области пропускает их события к Panzoom для сброса состояния предыдущего drag-жеста; мобильные стили задают естественную высоту подписи без внутреннего скролла, изображение высотой 78 px и уменьшенные элементы управления, а крестик размещён над карточкой; каталог также содержит контейнер превью `catalog-gallery`, пояснение `catalog-intro`, заголовок «Популярные темы:» и отдельную угловую кнопку с активной и неактивной PNG-иконками;
- на публичной странице готовых работ отсутствует блок `site-search`.
- главная содержит hero-баннер, заголовки «Больше возможностей для вашей кухни» без точки и «Почему выбирают стекло для кухни?», полноширинные секции предложений, преимуществ и последних работ, три карточки предложений, шесть некликабельных карточек преимуществ, три последние кликабельные фотографии работ и квадратную ссылку на полную галерею. Тест создает четыре готовые работы, проверяет три новые в правильном порядке и общий Fancybox с именами без описаний; прежний `product-number` проверяется как редирект на `/skinali/?q=...`.

## `TagPageAndSitemapTests`

Десять тестов страницы тега, SEO-метаданных, хлебных крошек, навигации по категориям и sitemap проверяют:

- вывод только опубликованных изображений, счетчика, SEO-title, meta description и canonical;
- отсутствие поисковой формы, наличие номера поверх превью, каталожной Fancybox-карточки с отключённым Hash-плагином истории, покупки, избранного и некликабельного текста тегов;
- HTTP 200 и `noindex,follow` для существующего пустого тега, 404 для неизвестного slug;
- включение в `/sitemap.xml` главной, каталога, готовых работ, дизайнера и контактов;
- включение только непустых категорий и тегов с опубликованными изображениями;
- единственный SQL-запрос списка категорий каталога и исключение из десктопной и мобильной навигации категорий без опубликованных изображений;
- SEO-title, meta description и canonical индексируемых постоянных страниц и категорий;
- уникальные H1 общего каталога и страницы категории;
- переопределение H1, SEO-title, meta description и вводного текста значениями из `TagPict` и `Category`, включая перенос строки и отсутствие лишнего стандартного подзаголовка категории;
- `noindex,follow` и canonical без GET-параметров для поиска и цветового фильтра;
- доступные визуальные цепочки и соответствующий валидный `BreadcrumbList` с абсолютными URL на страницах каталога, категории, тега, готовых работ, дизайнера и контактов; главная остаётся без крошек;
- сохранение визуальных крошек без JSON-LD на страницах с `noindex,follow`;
- отсутствие ORM-запросов при формировании метаданных крошек и безопасное экранирование динамического названия, способного преждевременно закрыть `<script>`.

## `RobotsTxtTests`

Два теста корневого `/robots.txt` проверяют:

- HTTP 200, тип `text/plain; charset=utf-8` и часовой публичный HTTP-кеш;
- динамический запрет текущего `ADMIN_URL` и маршрута обработки контактной формы;
- `Clean-param` для распространённых рекламных параметров и абсолютный `Sitemap` от `PUBLIC_SITE_ORIGIN`;
- поддержку GET/HEAD и HTTP 405 с корректным `Allow` для POST.

## `RemovedTestRouteTests`

Один тест фиксирует отсутствие имени маршрута `cat` и ответ HTTP 404 для удалённого тестового URL `/cats/<id>/`.

## `PaginatorTemplateTests`

Два теста общего шаблона пагинации проверяют точные цели двойных стрелок на пять страниц назад и вперёд, а также скрытие каждой кнопки, когда полный переход на пять страниц в соответствующую сторону невозможен.

## `CatalogSearchTests`

Тринадцать тестов фиксируют новый поисковый контракт:

- NFKC-совместимую нормализацию, `casefold()`, эквивалентность `ё`/`е`, все поддерживаемые пробельные и знаковые разделители и распознавание одиночного числового номера;
- русские формы счетчика для значений 1, 2, 5, 11 и 21;
- удаление повторных слов с сохранением порядка и канонической строки, допуск одиночного однозначного номера, а также ошибки формы для пустого, пунктуационного, одно- или двухсимвольного текстового слова, более пяти уникальных слов, слишком большого числового номера или более 100 символов запроса;
- автоматическое обновление `normalized_tag` при обычном сохранении и `update_fields`, дружелюбное отклонение нормализованных дублей основных тегов и синонимов, нормализацию синонима, запрет многословного или пунктуационного синонима и совпадения с основным тегом;
- глобальную AND-семантику на URL категории: `q` отключает категорию, цвет и панели фильтров, точный синоним участвует в поиске, превью результата показывает номер изображения, каталожная Fancybox-галерея не использует Hash-плагин истории, а неизвестный slug категории возвращает 404;
- порядок по релевантности: точный синоним находится выше частичного вхождения в основной тег;
- точный поиск опубликованного изображения по `Pict.name` и исключение снятого с публикации номера;
- отсутствие поиска по `Pict.alt`;
- счетчик, пустое состояние, сохраненные чипы и URL удаления одного слова; удаление последнего слова ведет в полный каталог;
- отдельное состояние невалидной формы с `role="alert"`, без каталожных карточек;
- общий размер страницы 30 для каталога и страницы тега, сохранение URL-кодированного `q` в пагинации и четыре запроса ORM-выборки списка без полного HTTP-рендера: `COUNT`, `SELECT Pict` и два prefetch для тегов и категорий;
- одинаковое число SQL-запросов `count()` для одного и пяти поисковых слов: слова добавляют подзапросы в один SQL, а не отдельные обращения к БД.

Подробный контракт поискового модуля: [search.md](search.md).

Класс `DesignerPageTests` проверяет страницу «Услуги дизайнера»: основные информационные разделы, выделенную ссылку «Напишите нам» в порядке покупки по номеру изображения, отмеченную стабильным кодом фиксированную стоимость `5$`, отсутствие прежних `30 BYN`, баннер эксклюзивной разработки с иллюстрацией, CTA «Обсудить идею», условия бесплатного предоставления каталожных изображений и три ссылки на страницу контактов.

Класс `SessionFavoritesTests` проверяет:

- добавление и повторное удаление изображения из сессии;
- `noindex,follow` и self-canonical персональной страницы `/favorites/`;
- независимость избранного у двух браузерных сессий;
- вывод недавно добавленных элементов первыми, номера поверх превью и в тексте карточки, описания и общей с каталогом Fancybox-разметки `catalog-gallery` без угловой иконки избранного на превью;
- скрытие пустого пункта «Избранное», его показ последним пунктом после добавления, единый темный счетчик адаптивного меню, активную угловую иконку каталога и кнопку в галерее;
- повторное использование в «Избранном» шаблона каталожной подписи с кнопкой удаления, а также расположенную после карточек общую кнопку публикации актуального списка номеров без ссылок; список сервисов позиционируется над кнопкой и не сдвигает блоки страницы;
- запрет GET для переключателя и ответ 404 для несуществующего или снятого с публикации изображения;
- автоматическое удаление снятого с публикации изображения из сохраненного списка и счетчика избранного.

Класс `FinishedWorkTests` проверяет:

- обратную связь `Pict.finished_works`, получение категорий через связанное изображение и сохранение готовой работы после удаления `Pict` с обнулением ссылки;
- публичный маршрут, пункт меню, квадратные карточки с шестиколоночной широкой сеткой и двумя колонками до 900 px, а также Fancybox-разметку с именем и номером изображения без описания и категории в подписи;
- отсутствие номера и поля категории в подписи после потери необязательной связи;
- сортировку по новизне, пагинацию по 6 работ, класс `catalog-pagination` и обозначение текущей страницы через `aria-current`.
- общий с каталогом список категорий, фильтрацию через `?category=<slug>`, исключение работ другой категории и работ без каталожной связи, сохранение категории при переходе между страницами, мобильный диалог и 404 для неизвестного slug.
- исключение снятой с публикации работы из полной галереи и блока последних работ на главной;
- уменьшенные размеры миниатюр готовой работы в admin, условное появление галереи связанных работ в форме изображения и подключение общего модального просмотрщика исходных файлов.

Изображения каталога создаются как настоящие временные JPEG в изолированном `MEDIA_ROOT`, чтобы рендеринг страниц также проверял работу `sorl-thumbnail`. Для готовых работ, где содержимое файла не участвует в проверке, используются ORM-записи со строковыми путями.

## Рекомендуемые области покрытия

- Модели: URL, строковые представления, связи и автоматический номер `Pict`.
- Views: дополнительные сочетания поисковых слов и ранжирования, фильтры цвета/тега, пагинация, неверные slug.
- URL: reverse/resolve для обоих маршрутов с именем `skinali` и маршрута `designer` без завершающего `/`.
- Admin/form: создание первой записи и вычисление следующего `name`.
