# `skinali/pict/urls.py`

## Назначение

Определяет публичные маршруты приложения `pict`. Подключается без префикса из корневого URLconf.

## Таблица маршрутов

| URL | Имя | View | Назначение |
|---|---|---|---|
| `/` | `home` | `PictHome` | главная страница; совместимость со старым поисковым параметром |
| `/about/` | `about` | `about` | контакты |
| `/favorites/` | `favorites` | `favorites` | избранные изображения текущей сессии |
| `/favorites/shared/` | `favorites_shared` | `favorites_shared` | GET проверяет подписанную подборку; автоматический POST с CSRF объединяет её с избранным |
| `/favorites/clear/` | `favorites_clear` | `clear_favorites` | POST с CSRF очищает избранное текущей сессии с сохранением отложенной подборки |
| `/favorites/toggle/<int:pict_id>/` | `favorite_toggle` | `toggle_favorite` | добавить изображение в избранное или удалить его; только POST |
| `/contact/request/` | `contact_submit` | `submit_contact_form` | серверная проверка контактной формы; только POST |
| `/foto-skinali-iz-stekla/` | `finished_works` | `FinishedWorkList` | публичная галерея готовых работ |
| `/skinali/` | `skinali` | `SkinaliAll` | весь каталог и глобальный поиск |
| `/skinali/image/<slug:slug>/preview/` | `pict_large_preview` | `pict_large_preview` | создание крупного превью опубликованного изображения по запросу и перенаправление на кешированный файл |
| `/skinali/image/<slug:slug>/` | `pict_detail` | `PictDetail` | индексируемая индивидуальная страница опубликованного изображения |
| `/skinali/<slug:slug_cat>/` | `skinali` | `SkinaliSlug` | каталог категории и поиск в её пределах |
| `/designer/` | `designer` | `designer` | услуги дизайнера |
| `/tag/<slug:tag_slug>/` | `tag` | `PictTag` | глобальная страница опубликованных изображений по тегу; неизвестный slug возвращает 404 |

## Параметры

- Оба URL каталога принимают GET-параметр `q`. На `/skinali/` поиск охватывает все опубликованные изображения, а на URL категории ограничивается её изображениями. Параметр `color` в режиме поиска игнорируется; неизвестный `slug_cat` по-прежнему возвращает 404.
- Без `q` каталог и страница тега принимают до трёх повторяемых GET-параметров `color` со значением `Color.slug_color`. Каждый следующий цвет сужает выборку: изображение должно иметь все выбранные цвета.
- Главная страница поддерживает только прежнюю ссылку `/?product-number=<значение>` и отвечает перенаправлением на `/skinali/?q=<значение>`. Поисковая выдача на `/` больше не рендерится.
- Стандартный параметр `page` обрабатывается пагинацией `ListView`. Каталог, категории, поиск и страницы тегов выводят по 30 изображений; `q` сохраняется в ссылках страниц валидной поисковой выдачи, а страница тега также сохраняет все выбранные `color`. Номер индексируемой страницы тега без цветового фильтра входит в canonical; цветовые варианты получают `noindex,follow` и canonical чистого URL тега.
- Индивидуальная страница разрешает запись по стабильному `Pict.slug` и возвращает 404 для неизвестного либо снятого с публикации изображения. Префикс `/skinali/image/` отделяет её от одноуровневых slug категорий.
- Маршрут крупного превью по тому же slug доступен только для опубликованного изображения. Он создаёт вариант шириной до 1920 px при первом обращении и отвечает временным перенаправлением на файл в media-кеше; ответ перенаправления имеет `Cache-Control: no-store`, чтобы не сохранять устаревший адрес после замены исходника.
- Переключатель избранного принимает ID `Pict` в URL, возвращает JSON с актуальной ссылкой публикации и отклоняет методы, отличные от POST. Попытка добавить 6-е изображение получает HTTP 409 и сообщение для Toast.
- `/favorites/shared/?data=…` принимает бессрочный подписанный токен максимум на 5 ID. GET сам не импортирует подборку, POST повторно проверяет подпись и публикацию и добавляет только новые изображения в пределах свободных мест. Не поместившийся остаток и прогресс хранятся в cookie для повтора. Финальный адрес — `/favorites/` без токена; прочие методы отклоняются. Подробности: [favorites.md](favorites.md).
- `/favorites/clear/` принимает только POST, возвращает перенаправление на `/favorites/` и не сбрасывает прочие данные сессии либо отложенную подборку. GET получает HTTP 405, отсутствие CSRF при включённой проверке — HTTP 403. Повторная очистка пустого списка допустима.
- Обработчик контактной формы принимает только значения белого списка `form_kind`: `callback`, `question`, `email_message` или `image_purchase`. AJAX-запрос получает JSON, обычный POST — HTML-страницу результата с сохранением введённых значений при ошибке. Финальная форма квиза использует отдельный служебный маршрут `/quiz/<trigger_key>/submit/`, описанный в [документации квиза](../quiz/overview.md).
- Страница готовых работ принимает стандартный GET-параметр `page` и выводит по 30 работ.

Полный контракт нормализации, ограничений, AND-семантики и ранжирования параметра `q` описан в [search.md](search.md).

## Особенности и риски

- Одно имя `skinali` назначено двум маршрутам. Reverse с аргументом `slug_cat` выбирает маршрут категории, без аргумента — общий каталог.
- Прежний `/designer` перенаправляется на `/designer/` через `CommonMiddleware` при стандартном `APPEND_SLASH=True`.
- Используется wildcard-импорт из `views`.

## Когда читать исходник

При изменении URL, имен маршрутов, slug/ID-параметров или привязки view.
